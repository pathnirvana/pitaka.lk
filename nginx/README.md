# nginx config for pitaka.lk
Copies of the live server config, versioned here. Not deployed by `dev/deploy.sh` (it needs sudo).

| File | On the server |
|---|---|
| `pitaka.lk.conf` | `/etc/nginx/conf.d/pitaka.lk.conf` |
| `nodeid_mapping.map` | `/etc/nginx/conf.d/nodeid_mapping.map` |

`nodeid_mapping.map` maps the old Sarala Tipitaka node ids (`/main?n=15100`, `/15100`) to tree keys
(`dn-1-1`). It was generated by misc-projects/ai-trans/bjt/apz-redirect/generate_redirects.js.
It currently sends those links to `https://open.tipitaka.lk/sin_apz/<key>`. When the new reader launches,
it will send them to `https://pitaka.lk/main/<key>` instead (see dev-docs/pitaka-flavor.md in pathnirvana/tipitaka.lk).

Install after a change:
```
scp nginx/pitaka.lk.conf nginx/nodeid_mapping.map <host>:/tmp/
ssh <host> 'sudo cp /tmp/pitaka.lk.conf /tmp/nodeid_mapping.map /etc/nginx/conf.d/ && sudo nginx -t && sudo systemctl reload nginx'
```
